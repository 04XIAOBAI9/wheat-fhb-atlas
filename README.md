# WheatFHB Atlas｜小麦赤霉病抗性区间图谱

WheatFHB Atlas is a public-benefit, evidence-backed map of published wheat Fusarium head blight resistance intervals and loci. It supports chromosome-by-chromosome exploration, coordinate and gene searches, and batch SNP overlap analysis.

小麦赤霉病抗性区间图谱是一个公益性在线工具，用于整理、展示和查询已有文献报道的小麦赤霉病抗性区间与位点。网站支持逐条染色体浏览、基因/坐标/区间查询，以及批量 SNP 与有证据抗病区域的重叠分析。
