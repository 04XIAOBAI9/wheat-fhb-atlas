# WheatFHB Atlas public release v0.4.0

This directory contains the controlled public layer: 220 strict-primary, RefSeq v1.0-comparable loci and aggregate longitudinal analyses.

The full local reproducibility archive contains 387 locus records, 25 study units, the screening queue, record-level coordinate audits, the research workbook, scientific report, and integrity-audit working files. Those materials are not included in this public directory before explicit release authorization.
